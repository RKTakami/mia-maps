## Cave view, and a freeze that needed a force-quit

Tested on macOS (Apple Silicon) against Mine In Abyss on 1.21.11. **The Windows
native is cross-compiled and compile-verified only — nothing in this release has
been run on Windows.** One jar carries both platforms.

### Three bugs worth updating for

**The game could hang hard enough to need a force-quit.** The section demoter
sorted by a field that other threads rewrite constantly, which makes TimSort
throw — and it threw *before* demoting anything, so once the world was busy
enough nothing was ever freed and the cache grew past its budget until the heap
gave out. Fixed in the companion `mia-voxy-rust` build; this release pairs with it.

**The 3D view could freeze on stale terrain.** Voxy's cleaner shuts a world down
when it looks idle and builds a fresh engine on next access — about 25 times in
one evening's play. Nothing downstream knew, so every cache kept serving data
from an engine that no longer existed, and could not recover while the camera
stood still. Caches are now keyed on which engine produced them.

**The fullscreen map could open black and stay black.** Its change-detection
state was committed before drawing, so a compose that bailed early (engine not up
yet) requested no tiles, which meant nothing could ever mark it dirty again.

### Cave view — press V

`RELIEF → VANILLA → CAVES`, in both the 2D map and the 3D view.

Underground the normal map paints the first solid cell below you, which is the
rock you are standing inside — a flat grey wash. Cave view paints only floors,
leaving solid rock dark so passages read against it. Depth is shaded from your
own level: **blue below, red above**, dimming with distance either way. Where the
map would be blank it also looks upward for a ledge, so walls can show an upper
passage without ever replacing the floor under your feet.

This is deliberately not the see-through-terrain feature removed in `dfeb3e5`.
The 2D slice is bounded to 48 blocks and may tunnel only 4 blocks through
unbroken rock; the 3D view keys on **reachability**, so a sealed chamber one cell
beyond a wall stays invisible however close it is. Above ground both are
identical to `RELIEF`. Those bounds are covered by tests.

### 3D view

- **Cutaway (`C`)** — drops everything between the camera and the plane through
  you. Looking down it takes the ceiling off. Implemented as a shader plane, so it
  cuts a straight edge through geometry and keeps the GPU renderer's cascade.
- **Cave Maps (`T`)** — draws terrain translucent, depth-sorted, so cave structure
  inside rock is visible. Off by default. Uses the CPU path, which is slower.
- **Compass rays** now pass through terrain and are always visible. They are a
  reference frame anchored on you, and one that vanishes into rock stops telling
  you which way north is exactly when you are buried.
- **Status line** shows mode, whether GPU or CPU is drawing, and cutaway state.
- The sampled box was 3:1 tall and framed at a third of the viewport; both fixed.
  Over-budget views now coarsen or mesh instead of dropping every Nth surface,
  which used to punch holes in solid ground.

### Known limits

- **1-block passages need a close zoom.** Detail is capped by a dense grid whose
  cost is cubic: at 512 blocks across, the best available is 4-block cells on Low
  and 2-block on Ultra. Sparse surface extraction is the fix and is not in this
  release.
- Cave Maps above ~85% reads as mush on deep terrain.
- `config/voxy_mia_light_zones.json` containing `"hi"` throws on every boot.
